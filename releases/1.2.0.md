## Français

### Pour les administrateurs

- **Fermeture temporaire.** Le temps d’une mise à jour, un administrateur ferme l’application à tous les autres rôles, avec un message de son choix (Configuration › Fermeture temporaire). Les membres voient ce message à la place des pages et ne peuvent pas se connecter ; les liens publics affichent le même message et les agendas abonnés (iCal) gardent leurs dates. Les administrateurs continuent d’utiliser l’application, avec un bandeau qui rappelle la fermeture, et la rouvrent d’un clic. La page montre un aperçu de ce que voient les membres.

### Corrections

- Message « Vous n’avez pas les droits nécessaires » traduit.

## English

### For administrators

- **Temporary closing.** During an update, an administrator closes the application to every other role, with a message of their choice (Settings › Temporary closing). Members see this message instead of the pages and cannot log in; public links show the same message and subscribed calendars (iCal) keep their dates. Administrators keep using the application, with a banner reminding them it is closed, and reopen it in one click. The page shows a preview of what members see.

- “You do not have the rights needed” message translated.
