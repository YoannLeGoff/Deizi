# Notes de version / Release notes

Une note par version de Deizi, publiée aussi dans les [versions GitHub](https://github.com/YoannLeGoff/Deizi/releases) du dépôt. La page À propos de l’application affiche le numéro de version (`DEIZI_VERSION` dans `lib/bootstrap.php`) et renvoie vers ces notes.

Numérotation `MAJEURE.MINEURE.CORRECTIF` (versionnage sémantique) : correctif pour une correction sans nouveauté, mineure pour des nouveautés compatibles, majeure quand une mise à jour demande une action de l’administrateur ou change un comportement établi. Étiquette Git `v1.1.0` pour chaque version.

À chaque version : écrire `releases/<version>.md` en français et en anglais (nouveautés pour les membres, pour les administrateurs, pour l’installation), passer `DEIZI_VERSION` à ce numéro, puis publier la version sur GitHub avec le même texte.

*One note per version of Deizi, also published in the repository’s [GitHub releases](https://github.com/YoannLeGoff/Deizi/releases). The About page of the application shows the version number (`DEIZI_VERSION` in `lib/bootstrap.php`) and links to these notes. Numbering is `MAJOR.MINOR.PATCH` (semantic versioning): patch for a fix without new features, minor for compatible new features, major when an update needs an action from the administrator or changes established behaviour. Git tag `v1.1.0` for each version. For each version: write `releases/<version>.md` in French and English, set `DEIZI_VERSION` to that number, then publish the release on GitHub with the same text.*
